# business_analysis: A single page website for a real estate agency, 'Orca real estate agents', hosted at orca.co. It includes static section

Status: draft

## outOfScope

- Dynamic property listings (no CMS, no admin panel).
- Contact form submission and handling.
- Google Maps or location embeds.
- User accounts or authentication.
- Blog or news sections.
- Search or filtering for properties.
- Integration with third-party real estate APIs or MLS.
- Analytics, tracking, or cookies consent (unless required by law).
- E-commerce or payment functionality.
- Live chat or support widgets.

## assumptions

- The user will provide all necessary textual content and images for each section.
- The domain orca.co will be configured to point to the hosted website.
- Social media links may be placeholders if specific platforms and URLs are not provided.
- No contact form is needed as per user clarification.
- No Google Maps embed is required.
- The user is responsible for obtaining rights to all images and content used.
- The static property listings will be manually updated by the developer when content changes.

## userStories

- As a visitor, I want to see an About Us section so that I can learn about the agency.
- As a visitor, I want to see a Services section so that I understand what the agency offers.
- As a visitor, I want to browse Property Listings so that I can see available properties.
- As a visitor, I want to find Contact information so that I can reach the agency.
- As a visitor, I want to read Testimonials so that I can gauge past client satisfaction.
- As a visitor, I want to see the Team section so that I know the people behind the agency.
- As a visitor, I want to access social media links so that I can connect with the agency on other platforms.

## acceptanceCriteria

- The page is a single, scrollable website with all listed sections clearly separated.
- Each section is populated with static content provided by the user.
- The About Us section contains agency description and background.
- The Services section lists all offered real estate services.
- The Property Listings section displays a static set of properties with images and descriptions.
- The Contact section includes essential contact details (address, phone, email) but no contact form.
- The Testimonials section shows curated client feedback.
- The Team section introduces key team members with photos and roles.
- Social media links are prominently displayed, linking to the agency's profiles (specific platforms and URLs are TBD — to be clarified by user).
- The design uses a pastel color scheme as the primary palette.
- The agency name 'Orca real estate agents' is prominently featured.
- The website is optimized for both desktop and mobile devices.
- All content is hardcoded as static assets; no CMS or dynamic data loading.
