# business_analysis: Build a modern, single-page CV/profile website for a software engineer with a luxury light theme (gold accents), ATS-fri

Status: draft

## outOfScope

- Server-side rendering or dynamic backend.
- Administrator interface for editing CV content.
- User authentication or personalization.
- Support for multiple languages or themes.
- Analytics, tracking, or cookie consent.
- Integration with any external APIs or databases.
- Hosting or deployment automation (beyond providing a Dockerfile or build script).

## assumptions

- The cv-data.json file exists in the project root with valid data conforming to the schema; its content is not validated by the page beyond basic existence checks.
- The avatar image (if provided) is a web-friendly format (PNG/JPG) accessible via a relative or absolute URL.
- Favicon is dynamically generated by drawing the avatar onto a small canvas and exporting as .ico (or using a default icon if no avatar).
- The site will be deployed as static files; hosting environment does not impact code beyond relative paths for resources.
- Third-party libraries (e.g., html2pdf.js, Intersection Observer polyfill if needed) are loaded from CDNs, but the core page works offline except for image URLs.
- Skill bar level is an integer between 0 and 100 representing proficiency percentage.
- PDF download uses html2pdf.js to clone the visible DOM, applying necessary adjustments for print layout; exact CSS capture is sufficient for the luxury theme.
- The luxury light theme design tokens are fully specified in a separate design doc; the implementation follows those tokens precisely.
- SEO meta tags are inserted dynamically via JavaScript after loading cv-data.json, but the page also has static fallbacks for basic indexability.
- The project does not require any backend, database, or external API integrations.

## userStories

- As a recruiter, I want to view the engineer's CV in an elegant, easy-to-read layout so I can quickly assess their qualifications.
- As a visitor, I want the page to display a professional photo and animated skill bars that convey proficiency levels at a glance.
- As a visitor, I want to download a high-quality PDF version of the CV that includes all information (dynamic elements rendered statically) for offline sharing.
- As a site owner, I want to update CV content by editing a single JSON file without touching code, enabling easy maintenance.
- As a search engine, I want the page to include JSON-LD structured data and Open Graph meta tags so the CV can be properly indexed and previewed.
- As a developer, I want a clear design specification (colors, fonts, spacing) and data schema to implement the site consistently.

## scopeQuestions

- Is the cv-data.json file included with the project or supplied externally by the user?
- What is the exact filename and location of the favicon if a separate default file is preferred? (Assumption: generated dynamically)
- Should the page include a contact form or links to external profiles (GitHub, LinkedIn)?
- Is there a need for print-specific CSS (e.g., page breaks) beyond what html2pdf.js provides?

## acceptanceCriteria

- The page must be a single, responsive HTML file with CSS and vanilla JavaScript, no framework required.
- CV data is loaded from a `cv-data.json` file in the project root, following a defined JSON schema (see assumptions).
- The JSON schema must include fields: name, title, summary, experience[] (company, role, dates, description), education[] (institution, degree, dates), skills[] (name, level 0-100), avatar URL, SEO metadata (title, description, og:title, og:description, og:image).
- The luxury light theme must use specified design tokens: primary background #FFFFFF, text #333333, gold accents #C9A84C, secondary gold #E5C158, font family 'Lora' (headings) and 'Open Sans' (body), max-width container 960px, base font size 16px, line height 1.6, section padding 40px 0, avatar size 200x200px rounded, skill bar height 12px with border-radius 6px, etc. (full design doc provided).
- Skill bars must animate: on viewport entry (using Intersection Observer), width transitions from 0% to the skill level over 1 second.
- PDF download must include all CV content and the avatar (if present). Dynamic elements like skill bars are rendered as static filled bars with percentage labels. PDF generation uses a library (e.g., html2pdf.js) to capture the exact CSS styling of the luxury theme, triggered by a download button.
- The page must embed JSON-LD structured data (schema.org/Person) mapped cleanly from cv-data.json fields: name→name, title→jobTitle, summary→description, avatar→image, experience→worksFor (array), education→alumniOf, skills→knowsAbout.
- SEO meta tags and Open Graph tags must be generated from the JSON data: <title> = name + ' - ' + title, <meta name='description'> = summary, og:title = name + ' - Professional CV', og:description = summary, og:image = avatar URL (or a default placeholder if none).
- Avatar is optional in JSON; if omitted, a placeholder (e.g., initials or generic icon) must be displayed on the web page, and the PDF includes that placeholder. favicon.ico must be generated from the avatar if provided, otherwise use a default favicon.
- The page must be fully accessible (semantic HTML, alt text, ARIA where appropriate).
- Code must be self-contained in a sandboxed worktree, with no external runtime dependencies beyond a PDF generation library loaded via CDN (if allowed).
- All TL change requests are addressed: spacing tokens provided, animation trigger clarified (viewport), avatar optional with fallback, favicon generation from avatar, cv-data.json schema specified, PDF captures CSS styling, JSON-LD and SEO mappings defined.
