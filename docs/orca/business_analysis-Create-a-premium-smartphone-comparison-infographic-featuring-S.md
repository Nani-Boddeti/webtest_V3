## outOfScope

- Dynamic or real-time data (e.g., live pricing, stock availability).
- Interactive features (e.g., hover effects, clickable elements, responsive design).
- Multiple variants or A/B testing of the infographic.
- Mobile-responsive or web-based delivery; final output is a static image.
- User account management or multi-user collaboration.
- Future phone model comparisons; this is limited to the specified phones.

## assumptions

- The exact specifications for both phones are provided by the user or are publicly known and can be accurately represented.
- The user will provide realistic product renders or authorize their generation via AI.
- The infographic will be generated programmatically using a design tool, headless browser, or graphics library.
- Pastel colors will be used for accents such as borders, highlights, or labels, not for the background.
- The final deliverable is a static image file, not an interactive web page.

## userStories

- As a user, I want a side-by-side comparison infographic of Samsung Galaxy S26 Ultra and iPhone 17 Pro Max.
- As a user, I want the infographic to display key specifications (display, processor, OS, cameras, battery, charging, weight, security, price, RAM/storage) for each phone.
- As a user, I want a minimalist, clean design with bold red titles, subtle shadows, sharp text, and pastel color accents on a white background.
- As a user, I want the infographic to be in ultra-high resolution, 4:5 aspect ratio, suitable for YouTube thumbnails.
